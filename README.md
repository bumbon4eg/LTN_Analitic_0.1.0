# LTN Analytic 0.1.1

Factorio 2.0 мод для продвинутых пользователей, которые хотят изучать работу
Logistic Train Network (LTN), жизненный цикл доставок и поведение поездов.
Мод собирает аналитические данные о доставках, заказах, событиях, поездах и
станциях, а затем периодически экспортирует их в версионированный JSON Lines
(JSONL) для внешнего анализа.

Мод не является самостоятельным пользовательским интерфейсом для просмотра
аналитики. Для полной работы потребуется собственная база данных и отдельное
приложение `gateway`, которое загружает JSONL в эту базу.

Перед установкой и использованием прочитайте [инструкцию проекта](docs/architecture.md)
и [инструкцию gateway](gateway/README.md). Эти файлы входят в репозиторий и
содержат актуальные требования, порядок запуска и описание протокола.

## Как устроен проект

```text
.
├── code/                 # Исходный Lua-код Factorio-мода
├── info.json             # Метаданные Factorio-мода
├── build.ps1             # Сборка Factorio-архива из code/ и info.json
├── schemas/              # JSON Schema общего протокола
├── gateway/              # Отдельный загрузчик JSONL в базу данных
├── docs/
│   └── architecture.md   # Архитектура и контракт проекта
└── .dev/                 # Локальные материалы разработки
```

`code/` — исходная структура репозитория. Factorio же требует `info.json` и
`control.lua` в корне установленного мода, поэтому запуску игры предшествует
сборка через `build.ps1`. Каталог `gateway/` в архив Factorio не попадает.

## Поток данных

```text
LTN events
    -> code/actions.lua
    -> code/buffer.lua
    -> code/jsonl.lua
    -> script-output/LTN_Analitic/data.jsonl
    -> gateway
    -> database
```

Экспорт выполняется каждые 360 игровых тиков (6 секунд). Каждый JSONL-пакет
содержит `protocol_version`, `world_id`, `sequence_number`, игровой `tick`,
активные заказы, события заказов, поезда и станции.

Формат пакета описан в [schemas/packet.schema.json](schemas/packet.schema.json).
Полное описание модулей, жизненного цикла и контракта находится в
[docs/architecture.md](docs/architecture.md).

## Требования

- Factorio 2.0
- Logistic Train Network версии 2.0.0 или новее

Дополнительные интеграции LTN перечислены в [info.json](info.json).

## Сборка и установка мода

В PowerShell из корня проекта выполните:

```powershell
.\build.ps1
```

Скрипт создаёт `dist/LTN_Analitic_0.1.1.zip`. Поместите ZIP-архив в каталог
`mods` Factorio. Убедитесь, что Logistic Train Network и необходимые зависимости
установлены, затем запустите игру с включённым модом.

Данные будут записываться в каталог `script-output/LTN_Analitic/`.

## Gateway

`gateway/` читает созданный модом JSONL-файл и загружает данные в базу данных.
Настройка и изменение этого приложения выполняются отдельно от Factorio-мода.
Инструкция запуска, настройки и граница ответственности описаны в
[gateway/README.md](gateway/README.md). Переменные подключения к базе данных перечислены в
[`gateway/.env_template`](gateway/.env_template), а зависимости — в
[`gateway/requirements.txt`](gateway/requirements.txt).

## Разработка

Команды отладки и детали внутреннего устройства описаны в
[документации по архитектуре](docs/architecture.md).
Файлы `schemas/` являются версионируемым контрактом между модом и `gateway`.
`protocol_version` относится к формату JSONL, а не к версии Factorio-мода.
Совместимые дополнительные поля не требуют увеличения версии. Переименование,
изменение типа, обязательности или смысла поля требует новой major-версии
протокола и одновременного обновления Lua-кода, схем, gateway и документации.
