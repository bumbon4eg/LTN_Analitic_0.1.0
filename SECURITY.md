# Security

## Секреты

Проект не должен хранить в репозитории:

- пароли PostgreSQL;
- connection strings с секретами;
- API tokens;
- рабочие `.env`;
- пользовательские Gateway-конфигурации.

Реквизиты конкретной базы относятся к экземпляру Gateway и **не должны находиться внутри Factorio-мода**.

## Текущая реализация Gateway

В текущем Python Gateway пароль PostgreSQL сохраняется в пользовательском `config.conf` в открытом виде. Поэтому этот файл должен оставаться доступным только владельцу соответствующего Windows-профиля и не должен передаваться вместе с модом или репозиторием.

## Если секрет попал в Git

Не ограничивайтесь удалением строки из последнего commit. Считайте секрет скомпрометированным:

1. замените пароль/token на стороне сервера;
2. отзовите старый секрет;
3. проверьте Git history;
4. удалите секрет из истории, если это требуется политикой проекта.

## Подозрительная активность

Для сообщения о потенциальной уязвимости используйте приватный канал связи с владельцами проекта, а не публичный issue.
