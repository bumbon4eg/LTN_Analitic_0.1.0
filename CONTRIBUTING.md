# Contributing

Спасибо за интерес к проекту.

## Перед изменением кода

Определите, в какой части системы находится изменение:

```text
Factorio runtime → code/
JSONL contract  → schemas/
Gateway          → gateway/
Documentation    → docs/
```

Не переносите логику между этими слоями без необходимости.

## Factorio

Используйте только Factorio 2.0 API для текущей ветки проекта. При работе с LTN сверяйтесь с фактическим remote API установленной версии LTN.

Если API неизвестен, сначала проверьте официальную документацию и существующие вызовы проекта.

## JSONL

Любое изменение формата должно сопровождаться проверкой:

- producer в Lua;
- JSON Schema;
- Gateway parser/Pydantic;
- потребителей данных;
- документации.

## Безопасность

Никогда не отправляйте в commit:

```text
.env
config.conf
пароли
API tokens
production connection strings
```

Для локальных секретов используйте `.env` или пользовательскую конфигурацию вне Git.

## Pull request

В описании изменения укажите:

1. что изменено;
2. зачем это нужно;
3. какие файлы затронуты;
4. какие проверки выполнены;
5. какие ограничения или известные проблемы остались.
