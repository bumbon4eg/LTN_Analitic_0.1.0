# Gateway

Gateway — отдельное Python-приложение с Tkinter GUI. Оно читает JSONL, созданный Factorio-модом, преобразует snapshots в модели и загружает orders/events в PostgreSQL. Gateway не входит в Factorio-архив.

## Запуск

Из каталога `gateway/`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Tkinter входит в стандартную поставку Python для Windows; дополнительные GUI-пакеты не требуются.

## Настройка и интерфейс

При первом запуске открывается мастер: JSONL-источник, PostgreSQL как назначение, параметры подключения, проверка и сохранение. При следующих запусках отображается рабочая панель с проверкой подключения, кнопкой настроек и запуском импорта. Настройки редактируются все сразу на одной странице.

В настройках задаются:

- путь к JSONL;
- адрес сервера и порт PostgreSQL;
- имя базы, пользователь и пароль;
- флаг SSL/TLS.

В поле пароля есть кнопка показа значения. Проверка подключения выполняет `SELECT 1`; при успешной первоначальной настройке параметры сохраняются. Импорт и тест соединения работают в фоновых задачах, чтобы интерфейс оставался отзывчивым.

## Файлы конфигурации

Путь к JSONL по умолчанию:

```text
%APPDATA%\Factorio\script-output\LTN_Analitic\data.jsonl
```

Параметры и статистика UI сохраняются в:

```text
%APPDATA%\LTN_Analitics_gateway\config.conf
```

`config.conf` содержит JSON: `source_jsonl_path`, секцию `database` и `statistics`. В database хранятся `db_user`, `db_password`, `db_host`, `db_port`, `db_name`, `db_ssl`. Старый файл без `db_ssl` остаётся совместимым; default — `false`. Для legacy-запусков загрузчик может читать `gateway/.env`, если AppData config ещё отсутствует.

Пароль хранится в `config.conf` открытым текстом. Защитите файл правами пользователя Windows и не публикуйте его.

При включённом SSL gateway использует TLS context с проверкой сертификатной цепочки и hostname. Если база использует сертификат от частного CA, добавьте CA в системный trust store Windows либо установите доверенный сертификат; не отключайте проверку сертификата ради обхода ошибки.

## Импорт

1. JSONL читается построчно; пустые строки пропускаются, ошибка JSON содержит номер строки.
2. Каждый packet преобразуется в `GameSnapshotSchema` и модели orders/events.
3. SQLAlchemy проверяет соединение и создаёт отсутствующие таблицы.
4. Orders и events записываются порциями по 500.
5. В UI сохраняются число запусков, snapshots и реально вставленных orders/events, а также время последнего успешного импорта.

Порядок вставки: сначала orders, затем events. Event service оставляет только events, чьи orders существуют. Order ID в БД — `world_id:order_id`; репозитории используют PostgreSQL `ON CONFLICT DO NOTHING`, поэтому повторная обработка того же JSONL идемпотентна. JSONL-файл не удаляется и не очищается gateway автоматически.

## Ответственность и ограничения

Gateway использует схемы из общего каталога `schemas/`; изменения формата должны согласованно обновляться в моде и gateway. См. [контракт данных](data-contract.md), [архитектуру проекта](architecture.md) и [инструкцию разработки](development.md).
