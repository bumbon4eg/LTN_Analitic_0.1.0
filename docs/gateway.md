# Companion Gateway

Этот репозиторий содержит только Factorio-мод и его JSONL-контракт. Приложение для чтения JSONL и импорта данных распространяется отдельно:

- [Исходный код и инструкция LTN Analytics Gateway](https://github.com/bumbon4eg/LTN-Analytics-Gateway/tree/master)
- [Скачать ZIP исходного кода](https://github.com/bumbon4eg/LTN-Analytics-Gateway/archive/refs/heads/master.zip)
- [Страница Releases](https://github.com/bumbon4eg/LTN-Analytics-Gateway/releases)

Сведения об установке и доступных пакетах Gateway публикуются в его репозитории и на странице Releases.

Мод не требует Gateway для игры. Когда запись включена в настройках мода, JSONL создаётся в `script-output/LTN_Analitic/data.jsonl` и может быть обработан внешним приложением. Формат описан в [контракте JSONL](data-contract.md).
