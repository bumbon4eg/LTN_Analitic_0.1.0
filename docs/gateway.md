# Gateway

`gateway` — внешнее приложение проекта. Его задача — принять JSONL, созданный Factorio-модом, преобразовать данные и загрузить поддерживаемые сущности в PostgreSQL.

Gateway **не является Factorio-модом** и не должен попадать в каталог мода.

> Текущий снимок проекта содержит Python/Tkinter-реализацию. Standalone `gateway.exe` — следующий этап распространения.

---

## Текущая архитектура

```text
JSONL
  │
  ▼
read_jsonl()
  │
  ▼
Pydantic / formatter
  │
  ▼
OrderORM / OrderEventORM
  │
  ▼
SQLAlchemy + asyncpg
  │
  ▼
PostgreSQL
```

GUI запускается отдельно и выполняет операции в фоновых задачах, чтобы обработка БД не блокировала окно.

---

## Первый запуск

Если пользовательская конфигурация отсутствует, открывается мастер из четырёх шагов:

1. **Источник данных** — путь к JSONL;
2. **Назначение данных** — PostgreSQL;
3. **Реквизиты PostgreSQL**;
4. **Проверка и сохранение**.

После успешной проверки Gateway сохраняет настройки и открывает dashboard.

---

## Что настраивается

Текущая версия хранит:

```text
source_jsonl_path

db_user
db_password
db_host
db_port
db_name
db_ssl

statistics.runs
statistics.snapshots_processed
statistics.orders_sent
statistics.events_sent
statistics.last_run_at
```

Путь конфигурации:

```text
%APPDATA%\LTN_Analitics_gateway\config.conf
```

---

## Проверка PostgreSQL

Кнопка проверки выполняет соединение с PostgreSQL и тестовый запрос:

```sql
SELECT 1;
```

При рабочем соединении Gateway также может создать отсутствующие таблицы моделей при инициализации БД.

Текущая ORM-модель содержит как минимум:

```text
orders
order_events
```

Для первого запуска пользователь БД должен обладать достаточными правами для подключения и создания таблиц в целевой схеме.

---

## SSL/TLS

При выключенном SSL Gateway подключается без TLS.

При включённом SSL создаётся стандартный `ssl.create_default_context()`, поэтому сертификат сервера и имя хоста должны проходить стандартную проверку доверия.

Если PostgreSQL использует сертификат от собственного CA, добавьте CA в доверенное хранилище Windows или используйте другой корректно доверенный сертификат. Отключение проверки сертификата не является штатным способом устранения ошибки.

## Импорт

`import_jsonl_data()` в текущей версии работает как пакетный импорт:

```text
открыть весь JSONL
      ↓
прочитать строки
      ↓
разобрать JSON
      ↓
преобразовать snapshots
      ↓
собрать orders/events
      ↓
подключиться к PostgreSQL
      ↓
вставить batches по 500
```

Пустые строки игнорируются. Повреждённый JSON приводит к ошибке с номером строки.

JSONL-файл не удаляется и не очищается автоматически.

---

## Идемпотентность

Gateway использует составной идентификатор order:

```text
world_id:order_id
```

Event хранит UUID события. Репозитории используют PostgreSQL-конфликт-устойчивые вставки, поэтому повторная обработка тех же идентификаторов не должна создавать дубли.

Это **идемпотентность на уровне данных**, но не полноценный incremental file cursor: текущая версия повторно читает весь файл.

## Рабочее окно

После настройки dashboard показывает:

- количество запусков;
- количество отправленных orders;
- количество отправленных events;
- время последнего успешного импорта;
- источник JSONL;
- текущие параметры назначения;
- возможность проверить соединение;
- возможность изменить настройки;
- кнопку ручного запуска импорта.

---

## Безопасность

Текущая реализация хранит пароль PostgreSQL в конфигурации пользователя в открытом виде.

Поэтому:

- не отправляйте `config.conf` другим людям;
- не коммитьте конфигурацию в Git;
- не вставляйте реальный пароль в README, issue или screenshots;
- используйте отдельную учётную запись БД с минимально необходимыми правами.

Для standalone-версии планируется защищённое хранение секрета средствами Windows.

---

## Будущая standalone-версия

Целевой пользовательский сценарий:

```text
gateway.exe
    ↓
первый запуск → мастер
    ↓
сохранить настройки
    ↓
рабочее окно
    ↓
постоянно читать новые JSONL-записи
    ↓
отправлять в БД
```

При этом реквизиты БД не будут находиться внутри Factorio-мода. Пользователи получат одинаковый мод, а каждый экземпляр Gateway сможет иметь собственное назначение данных.
